# PropMind Visual Redesign Mapping (`VISUAL_REDESIGN_MAPPING.md`)

## 1. Visual Design Benchmark & Aesthetic System
Based on the provided PropMind Luma-inspired architectural editorial reference, the visual redesign transforms the existing generic indigo/slate SaaS appearance into a **warm ivory, deep forest-green, muted sage, and champagne-gold editorial luxury real estate aesthetic** while preserving 100% of existing routes, React hooks, API integrations, form schemas, authentication flows, and business logic.

### Shared Design Tokens
- **Color Palette**:
  - **Canvas / Warm Ivory (`ivory`)**: `#FAF7F2` (primary background), `#F3EFE6` (secondary warm cream surface / trust strip), `#FFFFFF` (elevated card surface), `#E6E0D3` (hairline architectural borders).
  - **Deep Forest Green (`primary` / `forest`)**: `#1B3126` (hero/navigation/primary action), `#14251C` (deepest hover/footer), `#243F31` (elevated dark green card/banner).
  - **Muted Sage (`sage` / `secondary`)**: `#5A7363` (For Sale pill, verified badges, subtle botanical accents), `#EBF0EC` (soft sage tint surface).
  - **Champagne Gold (`gold` / `champagne`)**: `#C9A96E` (editorial accent typography, For Rent pill, crest icon, champagne border highlights), `#F7F1E3` (warm champagne badge background).
  - **Charcoal & Warm Stone Typography**: `#1C2420` (primary ink), `#5A625D` (muted body text), `#888F8A` (uppercase editorial micro-labels).
- **Typography**:
  - **Editorial Serif (`font-serif` — Cormorant Garamond / Playfair Display)**: High-contrast display headings (`Find. Verify. Invest. with Confidence.`, `Discover the finest properties in Indore`, page headers, property titles, passport headings).
  - **Clean Geometric Sans (`font-sans` — Plus Jakarta Sans / Inter)**: UI controls, navigation links, specs, prices, badges, and data tables.
  - **Editorial Eyebrow Labels**: Uppercase tracked micro-headings (`tracking-[0.2em] text-xs font-semibold`) paired with a thin horizontal champagne/stone rule (`h-px w-12 bg-amber-600/40`).
